# Player-1 project page

The static project page for **Player-1: Learning to Play from Synthetic Experience**.

Published at <https://player-1-project.github.io/>.

The site sources are maintained in `game-gym/project_page/`. This repository contains the built website and its GitHub Pages deployment workflow. Enable GitHub Actions as the Pages publishing source; pushes to `main` then deploy the site.

Released resources:

- [Player-1-Data](https://huggingface.co/datasets/yyyang/Player-1-Data)
- [Player-1-9B](https://huggingface.co/yyyang/Player-1-9B) and [Player-1-35B-A3B](https://huggingface.co/yyyang/Player-1-35B-A3B)
- [Code: Gym, training, and evaluation](https://github.com/TencentARC/Player-1)
